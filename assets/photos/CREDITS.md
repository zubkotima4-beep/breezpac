# Фотографии сайта

Все фотографии на сайте — демонстрационные материалы с Wikimedia Commons.
Они показывают процессы, материалы и оборудование, но **не являются съёмкой компании «Бриз»**.
Перед публикацией сайта замените их на собственные фотографии производства, сохранив имена файлов.
Для галереи используются пары `assets/photos/<name>-thumb.jpg` и `assets/photos/<name>-full.jpg`;
для карточек услуг достаточно `-thumb`.

Изображения масштабированы для веба. Производные изображения распространяются по тем же лицензиям,
