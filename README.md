# Бриз — полиграфия в Климовске

Статический многостраничный сайт полиграфической компании «Бриз» на русском
языке: без сборщиков, фреймворков и базы данных. Всё открывается обычным
браузером, стили и скрипты лежат рядом с HTML.

## Концепция

Тихая редакционная вёрстка в духе печатного каталога: крупные документальные
фотографии, тонкие линейки, много воздуха, асимметричные сетки и сдержанная
типографика. Вместо карточек-коробок и «корпоративных» блоков — развороты,
подписи как в журнале и спокойный ритм страницы.

Фотографии взяты из Wikimedia Commons и показывают реальные процессы,
материалы и оборудование. Это демонстрационные кадры, а не съёмка «Бриз»;
на сайте это явно подписано. Проекты в портфолио — графические концепты,
а не документированные работы компании, о чём также сказано на странице.

Палитра:

- черничная ночь — `#1F1D36`;
- тёплая бумага — `#F4F0E7`;
- светлая бумага — `#FBF8F1`;
- дымчатый шалфей — `#A8BBA3`;
- светлый шалфей — `#E3E9DA`;
- глубокий шалфей — `#6F8569`.

Типографика: **Prata** (крупные заголовки), **Golos Text** (текст),
**Playfair Display Italic** (акцентные курсивные строки), **JetBrains Mono**
(метки, цифры, подписи). Все шрифты размещены локально в `assets/fonts`,
внешние шрифтовые сервисы не используются.

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная: обложка, манифест, услуги, материал, работы, производство, фотогалерея, процесс, FAQ, финальный призыв |
| `services.html` | Шесть направлений, ориентировочные цены, липкое меню разделов |
| `portfolio.html` | Восемь графических концептов и фильтры по категориям |
| `photos.html` | Фотогалерея из 12 кадров: лайтбокс, подписи, авторы и лицензии |
| `contacts.html` | Телефоны, адрес, сборщик сообщения для WhatsApp, схема, реквизиты |
| `privacy.html` | Политика конфиденциальности |
| `404.html` | Страница ошибки |

Калькулятор и блок «расчёта стоимости» удалены полностью. Вместо них —
понятные ориентиры в ценах и предложение обсудить тираж по телефону.

## Что проверить до публикации

1. **Телефоны.** Номера взяты из открытых справочников. Позвоните на каждый
   и подтвердите актуальность. Основной номер на сайте — `+7 495 956-20-28`.
2. **WhatsApp.** Заявка ведёт на `+7 925 500-67-27` через `wa.me`. Убедитесь,
   что номер действительно подключён к WhatsApp, или замените его в
   `js/main.js` и в ссылках на страницах.
3. **Часы работы.** На сайте сознательно нет вымышленного графика: указано
   «время визита — по телефону». Если есть подтверждённые часы, их можно добавить
   в шапку и контакты.
4. **Адрес производства.** `1к13` указан как адрес производственной площадки
   и визита по данным пользователя. Юридический адрес по ЕГРЮЛ — дом 1,
   помещение 232. Подтвердите, что по адресу `1к13` действительно можно приехать
   и что визит возможен.
5. **Цены и сроки.** Все цены на `services.html` — ориентировочные и требуют
   подтверждения. Сроки в процессе и карточках — ориентиры, а не гарантия.
6. **Портфолио.** Проекты на `portfolio.html` — графические концепты, а не
   документированные работы компании. На странице есть пометка об этом.
   Замените на реальные проекты или оставьте как демонстрацию возможностей.
7. **Фотографии.** Все фото в `assets/photos` — демонстрационные изображения
   с Wikimedia Commons. Это не съёмка «Бриз». Перед публикацией замените их
   на собственные фото цеха, сохранив имена файлов.
8. **Реквизиты.** Перед сделками запрашивайте свежую выписку ЕГРЮЛ. На странице
   контактов есть соответствующая оговорка.

## Форма заявки

Форма на `contacts.html` не отправляет данные на сервер. Она собирает текст
из имени, телефона, услуги и деталей, показывает его в поле и даёт две
кнопки: открыть WhatsApp с готовым сообщением или скопировать текст.
Это осознанное решение: нет фиктивной почты, нет хранения персональных данных
на хостинге и нет ложного ощущения, что заявка ушла.

## Локальный запуск

Сайт работает без сборки. Достаточно открыть `index.html` в браузере.
Для проверки ссылок и относительных путей удобнее поднять статический сервер
в корне проекта, например:

```powershell
# если установлен Python
python -m http.server 8765

# если установлен Node.js
npx serve .
```

Затем открыть `http://localhost:8765/`.

## Проверка

Сайт рассчитан на desktop и мобильные экраны от 320 px. Проверялись:
меню и ловушка фокуса, якоря и позиции прилипающих панелей, фильтры портфолио,
лайтбокс (закрытие, стрелки, Escape, возврат фокуса), сборщик заявки,
