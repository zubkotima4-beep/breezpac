2. Какие данные могут обрабатываться

Оператор может обрабатывать только те данные, которые вы сообщаете добровольно:

  • имя или иное обращение;
  • номер телефона;

  • иные сведения, которые вы решите указать в обращении.

При посещении сайта веб-сервер может автоматически фиксировать технические данные: IP-адрес, дату и время запроса, тип браузера и устройства, адрес запрошенной страницы. Эти сведения используются для обеспечения безопасности и стабильной работы сайта и не применяются для рекламного профилирования.

Форма на странице контактов не отправляет данные на сервер. Введённые имя, телефон, вид услуги и описание задачи остаются в вашем браузере и используются только для формирования текста сообщения.

Чтобы передать заявку, вы нажимаете кнопку и открываете WhatsApp. Сообщение отправляется только после вашего действия. При использовании WhatsApp действуют правила и политика конфиденциальности соответствующего сервиса; оператор не контролирует обработку данных внутри мессенджера.

Если вы не хотите использовать WhatsApp, позвоните по телефону +7 495 956-20-28 или по одному из мобильных номеров, указанных на странице контактов.

Сайт не использует рекламные пиксели, системы веб-аналитики и маркетинговые cookies. Шрифты и основные файлы сайта загружаются с самого сайта, без обращения к сторонним шрифтовым сервисам.

На сайте есть ссылки на внешние ресурсы: Яндекс Карты, WhatsApp, Wikimedia Commons и страницы лицензий Creative Commons. Переход по таким ссылкам происходит по вашему действию. После перехода начинают действовать правила соответствующего сайта, включая обработку технических данных и cookies.
